# Minimap tiles

Transparent PNGs, square, 128x128, one consistent painted pixel-art style (displayed at 22-40px with `image-rendering: pixelated`). Any missing file falls back to an ASCII glyph.

Required: corridor, chamber, empty, lair, trap, treasure, puzzle, event, npc, safe, stairwell, unknown, player
Optional: trap-sprung (falls back to trap)
